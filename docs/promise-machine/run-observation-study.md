protected-origin baseline or published runbook.

### C. Reimplement from issue #434

Rejected. #508 is open and may proceed in a separate worktree, but no shipped

Warden round on a knowingly red or under-inoculated tree.

Option A is the least complex construction that meets the source-bound
recovery policy. One step scaffolds and demonstrates the same complete public

  verifies the named target.

run branch at the exact start with all three chains verified, command shapes
preflight, and the five-line protected-origin status captured. Exit is the
complete semantic reconstruction, cumulative provenance, all 40 prior guards,
three causal repairs, bounded reporter-lead disposition, current ADR-015,
exact reporter, Promise bindings, absolute write/status evidence, and every
named demonstration green before audit.

The step is discrete because schema, runtime, path policy, snapshot semantics,
fixtures, guard map, and report projection form one public validator contract.
It satisfies Protasis's scaffold and final-demonstration fixed points in one
pull request. Splitting it would cross the audit boundary while known red
mechanisms remained.
